# M5 evaluation decisions

We adopted the following project rules on 7 November 2026 through the delegated approval confirmed in the project discussion.

We use the same M4 datasets for all M5 runs. We adopted the acceptance rules for all twenty cases, including G05, G08 and G15, with their documented APM ceilings. Each valid matching activity receives APM credit once; the denominator remains twice the requested trip duration. Repetition is also checked separately under IFR. We use RTC for required-tool coverage, not argument correctness, reasoning quality or final-answer accuracy.

The cases, code, data and sixty saved run records are unchanged. This document is the approval record. Regenerating the derived golden contract with the frozen evaluation code may restore its original pending-status text; that does not revoke this decision. M6 service/retry policy remains a separate decision before new experiments.
